# IDEAS — Registro vivo del proyecto

Este directorio guarda las ideas, decisiones, oportunidades, hipótesis y próximos pasos que surjan al diseñar la evolución de Miluaistudio hacia una plataforma más amplia.

## Cómo mantener este registro

- **No sobrescribir iteraciones anteriores.** Cada nueva sesión sustantiva se documenta en un archivo nuevo.
- Usar el formato `ITERACION-AAAA-MM-DD-NNN-TEMA.md`.
- En cada iteración registrar: contexto, ideas exploradas, decisiones tomadas, opciones descartadas y por qué, riesgos o puntos por verificar, y próximos pasos.
- Actualizar este índice cuando se agregue una iteración.
- Distinguir siempre entre hechos comprobados, observaciones del código, hipótesis y propuestas.
- No guardar tokens, contraseñas, datos bancarios, teléfonos personales ni otros secretos en este directorio.
- No considerar disponible un nombre de marca, dominio o usuario de redes hasta verificarlo.
- Las ideas son propuestas de trabajo, no decisiones comerciales definitivas salvo que se indiquen expresamente.

## Principio de producto vigente

Explorar una plataforma útil para ayudar a las personas a **crear, organizar, encontrar recursos confiables y conservar recuerdos de sus celebraciones**, comenzando por mejorar el producto existente y validando cada nueva área antes de ampliarla.

## Protocolo para futuras conversaciones

Cuando se produzca una nueva iteración de planificación con el usuario:
1. Revisar este directorio antes de proponer cambios para conservar continuidad.
2. Añadir un archivo nuevo con los nuevos aportes y decisiones.
3. Actualizar este índice con el enlace correspondiente.
4. Informar al usuario qué archivos se agregaron y enlazar al registro actualizado.
