Para deployar y subir fotos, necesitás un GitHub Personal Access Token con permiso de Contents read/write.

Si no tenés token: GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens. Dale permiso de "Contents" read/write al repo Miluaistudio. El token se guarda solo para esta sesión y se borra al cerrar la pestaña.
